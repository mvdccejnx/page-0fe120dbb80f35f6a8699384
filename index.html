客户端选择与官方下载

灵魂云采用标准订阅协议，可与主流加速器客户端配合使用。请根据操作系统选择合适工具，并从官方渠道或应用商店下载，再导入灵魂云订阅链接。客户端选择直接影响分流规则、耗电与稳定性，建议优先使用仍在维护的版本。

Windows 客户端

推荐 Clash Verge、Clash for Windows 或 v2rayN。安装后通过订阅 URL 导入节点，开启系统代理。使用前关闭其他冲突的代理软件，避免规则互相覆盖。

macOS 客户端

可使用 ClashX.Meta 或 Surge。Surge 适合需要精细分流的进阶用户。导入机场订阅并更新后，按延迟或地区选择节点即可。

Android 客户端

Clash Meta for Android、Surfboard 较为常用。请从发布说明或官网指引获取安装包，避免来源不明的 APK，以降低安全风险。

iOS 客户端

Shadowrocket、Quantumult X、Stash 等需通过 App Store 获取。添加灵魂云订阅后建议开启分流，减少国内访问被不必要代理。

多设备共享

操作说明

第一步：在官网完成订阅

注册灵魂云账号，选择基础版、旗舰版或团队版并完成支付。支付成功后进入用户中心复制 Clash 或通用订阅链接。

第二步：安装客户端

按照客户端选择一节对照系统下载应用，安装时允许必要的网络与 VPN/代理权限。

第三步：导入机场订阅

打开客户端的订阅或配置页面，粘贴链接并更新。成功后将出现灵魂云节点列表，可按地区或延迟排序。

第四步：选择节点并连接

日常可选用香港、日本或新加坡节点；需要流媒体时切换解锁节点；游戏可优先尝试专线。连接后确认出口与应用可用性。

日常维护

定期更新客户端与订阅。某条线路异常时直接切换即可。剩余流量可在官网用户中心查看，接近配额时可升级套餐。

节点与线路说明

灵魂云节点池包含港澳台、日韩、新马、美西美东及部分欧洲入口。普通线路适合网页与轻量应用；旗舰版增加高带宽与专线入口。共享机场在高峰时段可能出现负载变化，用户可通过延迟测试自行筛选可用节点，不必绑定单一线路。

常见问题

灵魂云是什么类型的服务？

灵魂云是提供机场订阅与 VPN 梯子加速的网络服务。用户购买套餐后获得订阅链接，在自选客户端中导入即可连接全球节点，用于网络加速、流媒体访问和游戏优化。开通与续费均以官网为准。

如何从官网完成客户端下载与选择？

灵魂云不强制绑定单一应用，而是兼容 Clash、Shadowrocket、v2rayN 等主流加速器。请在本页客户端专区对照系统选择，并从该客户端官方渠道下载，再导入灵魂云订阅。不要使用来路不明的一键修改包。

基础版、旗舰版和团队版怎么选？

轻度浏览与偶尔解锁可选基础版（每月 100GB、3 台设备）。经常观看流媒体或需要游戏加速建议旗舰版（每月 300GB、5 台设备、专线与优先工单）。多人同时在线或需要定制路由选择团队版（每月 1000GB、20 台设备）。按年付价格更低。

订阅链接泄露了如何处理？

立即登录灵魂云官网用户中心重置订阅或修改密码。重置后旧链接失效，请在各设备客户端中更新新地址。不要把订阅公开分享到群组或网盘。

连接后部分网站或应用仍无法访问？

先确认套餐权限，基础版仅为部分解锁。接着切换带解锁标识的节点，并更新客户端规则。部分平台会调整检测方式，可更换出口地区后重试。游戏请优先使用 IPLC 相关节点。

流量与设备数量如何计算？

流量按套餐月度配额统计，设备同时在线数量分别对应 3、5、20 台。超出设备上限可能造成连接不稳定。具体重置周期与统计口径以用户中心显示为准。
